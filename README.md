# 📚 Biblioteca API (Backend)

API RESTful construída em **Node.js** e **Express** para gerenciar uma biblioteca pessoal. Este projeto atua como o backend do aplicativo mobile da Biblioteca, permitindo operações de CRUD (Create, Read, Update, Delete).

## 🚀 Tecnologias Utilizadas
* Node.js
* Express
* CORS
* Nodemon (Desenvolvimento)

## 📋 Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

## 🔧 Como Baixar e Executar o Projeto

1. **Clone este repositório:**
   ```bash
   git clone [https://github.com/joao-cesa/app-backend-reactNative.git](https://github.com/joao-cesa/app-backend-reactNative.git)

2. **Instale as dependências:**

npm install

3. **Inicie o servidor em modo de desenvolvimento:**

npm run dev
